# Manuale utente Gdpr

Integra il [manuale actor-oriented](../manuale-uso-attori.md). Gdpr gestisce consensi, informative e diritti dell'interessato.

## Attori e uso

| Attore | Uso verificato |
|---|---|
| Utente normale/gruppo | Esprime, consulta o revoca consensi nei flussi disponibili. |
| Operatore privacy/admin | Gestisce richieste e trattamenti autorizzati. |
| Super-admin | Governa configurazione globale secondo policy. |

Non salvare il consenso solo nel browser.
