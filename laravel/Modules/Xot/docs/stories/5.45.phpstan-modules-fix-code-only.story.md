# XOT-5.45 — PHPStan Modules: fix solo codice

## Story

Come **tech lead quality**,
voglio `phpstan analyse Modules` a 0 errori **senza che l’agente tocchi `phpstan.neon`**,
così il gate misura debito reale e rispetta la policy «neon solo utente».

## Acceptance Criteria

1. [ ] Agente non modifica né crea alcun `*.neon`
2. [ ] `./vendor/bin/phpstan analyse Modules --memory-limit=-1 --no-progress` → `[OK] No errors`
3. [ ] Fix via tipi/PHPDoc/codice/test — non `@phpstan-ignore` di massa
4. [ ] Dev Agent Record + `phpstan-status.md` aggiornati

## Contesto misura (2026-08-28)

Partenza: **848** file_errors (≈130 app + ≈718 tests) con neon utente attuale
(baseline/ignore commentati dall’utente).
