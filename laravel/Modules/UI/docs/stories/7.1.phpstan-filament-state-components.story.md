# Story 7.1-UI — Contratti PHPStan componenti Filament state

## Story

Come maintainer UI, voglio rendere espliciti i contratti di state dei componenti Filament, affinché il modulo sia staticamente sicuro senza alterare il rendering.

## Acceptance Criteria

<!-- LOCKED. External dev tools must not edit Acceptance Criteria. -->

1. Il comando PHPStan canonico su `Modules/UI` termina con zero errori.
2. IconPicker, SelectState, IconStateColumn, SelectStateColumn, ImageSpatie e VideoSpatie hanno callback e state tipizzati coerentemente con Filament.
3. Output visuale, fallback e API pubbliche restano invariati.
4. Nessun ignore, baseline, config o `mixed` evitabile viene aggiunto.
5. Una sola doc PHPStan UI canonica viene aggiornata, collegando questa story e archiviando logicamente le indicazioni contraddittorie senza duplicarle.

## Tasks / Subtasks

- [ ] Catturare baseline per file e distinguere state, callback e media block (AC: #1, #2)
- [ ] Correggere i contratti nei sei componenti senza cambiare rendering (AC: #2, #3)
- [ ] Consolidare l'indicazione nella doc PHPStan UI esistente più autorevole (AC: #5)
- [ ] Rieseguire PHPStan e revisionare il diff per soppressioni (AC: #1, #4)

## Dev Agent Record

### Implementazione

- Verificati i sei componenti production: i callback Filament pubblici e i contratti state
  risultano già staticamente verdi, senza modifiche di rendering necessarie.
- Nel test state canonico, il resolver schema ritorna ora `Select` anziché `object`, gli
  array hanno value type espliciti e la fixture `HasOne` descrive correttamente related e
  declaring model.
- Le assertion costanti sulle transizioni sono state sostituite con verifica delle
  notifiche Filament realmente inviate; il test icone restringe il payload prima di
  verificarlo e usa `Safe\mkdir`.

### Evidenze

- Baseline exact scope: **15 findings**, tutti in `UiStateColumnsBehaviorTest`; i sei
  componenti production erano già verdi.
- PHP syntax: **7/7 file validi**.
- PHPStan exact scope: **15 → 0 findings**.
- Pest mirato: **17 passed, 54 assertions**, nessuno skip.
- PHPStan cold modulo: **240 → 225 findings**. I 225 residui sono interamente fuori
  owned scope e saranno suddivisi in story file-disjoint; AC #1 resta module-wide aperta.
- Scansione negativa: nessun ignore, baseline, config, skip o assertion tautologica.
- PHPMD non avviabile per incompatibilità vendor `PdependExtension::load()`/Symfony
  `: void`; PHP Insights non installato. Graphify non eseguito per handoff.

### Disposizione

In review per lo scope posseduto. AC #2-#5 soddisfatti; AC #1 resta aperta finché gli shard
dei 225 residui non rendono verde il cold module. Nessun widening è stato effettuato.
