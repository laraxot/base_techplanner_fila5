# Story UI-7.11: contratti residual coverage monolitico

## Story

Come owner UI, voglio risanare il residual coverage senza dividerne artificialmente il file,
così che ogni scenario rimasto verifichi un boundary reale e staticamente tipizzato.

## Baseline e cause radice

**43 findings / 1 file**: assertion determinate (19), proprietà/metodi statici o instance
inesistenti, Safe I/O, iterable/foreach non ristretti, tipi/return irrisolvibili e argomenti.
Il file è indivisibile per la regola file-disjoint ma resta entro un dev-day con scope unico.

## Acceptance Criteria

<!-- LOCKED. External dev tools must not edit Acceptance Criteria. -->

1. Ogni assertion coverage-only è sostituita da output, stato, notifica o eccezione specifica.
2. Reflection, proprietà, metodi e callback puntano ad API production reali.
3. I/O, iterable, foreach, argomenti e return hanno contratti esatti e risolvibili.
4. Il file è PHPStan-green e Pest passa senza skip/tautologie.
5. Nessuna suppression, baseline, `.neon`, alias, proxy o catch onnivoro viene aggiunto.
