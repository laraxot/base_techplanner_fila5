# Story UI-7.7: contratti Filament deep coverage

## Story

schema, proprietà e callback siano testati senza assunzioni impossibili.

## Baseline e cause radice

**16 findings / 1 file**: proprietà non dichiarate, assertion/funzioni già ristrette,
arity errata, metodo inesistente, iterable incompleto e tipi impossibili.
