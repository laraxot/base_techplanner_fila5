# Manuale utente Seo

Integra il [manuale actor-oriented](../manuale-uso-attori.md). Seo genera metadati, canonical, sitemap e robots dal contenuto owner.

## Attori e uso

| Attore | Uso verificato |
|---|---|
| Visitatore/utente | Consulta le pagine e i metadati pubblicati. |
| Editor/admin | Cura metadati nelle superfici autorizzate. |
| Super-admin | Governa configurazione SEO globale. |

Verificare sempre locale, canonical, stato di pubblicazione e crawler.
