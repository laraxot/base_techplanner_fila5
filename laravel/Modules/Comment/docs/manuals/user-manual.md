# Manuale utente Comment

Integra il [manuale actor-oriented](../manuale-uso-attori.md). Comment risolve il contesto e la policy del record owner.

## Attori e uso

| Attore | Uso verificato |
|---|---|
| Utente normale/gruppo | Inserisce commenti solo sui record autorizzati. |
| Moderatore/admin | Modera commenti secondo policy del dominio. |
| Super-admin | Governa accesso globale alle risorse esposte. |

Il rendering del componente non sostituisce la policy.
