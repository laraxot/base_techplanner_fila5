# Theme documentation map

Questa è la mappa di ownership della documentazione dei temi. I documenti
restano nelle rispettive cartelle `Themes/*/docs`; non vengono duplicati nel
modulo TechPlanner.

| Tema | Documentazione | Focus |
| --- | --- | --- |
| Meetup | [docs](./Meetup/docs/) | Folio/Volt, registrazione, accessibilità |
| Sixteen | [docs](./Sixteen/docs/) | UX mobile, contratti di accessibilità, decisioni |
| TwentyOne | [docs](./TwentyOne/docs/) | componenti, homepage, SEO e Blade |
| Two | [docs](./Two/docs/) | contenuti, conversione, WCAG e mappe |
| Zero | [docs](./Zero/docs/) | stato del tema e archivio storico |

## Regole di mantenimento

- La documentazione specifica del tema vive nel tema che la implementa.
- Le decisioni condivise dal progetto vanno nella wiki di progetto o nel modulo
  owner, con un link dal tema; non si copiano in cinque directory.
- Ogni nuovo documento deve essere collegato dall'indice locale o da un README
  locale; i file `_archive/` di Zero sono storico, non fonte corrente.
- Prima di aggiungere un documento cercare il tema e la wiki con QMD per evitare
  duplicati.
