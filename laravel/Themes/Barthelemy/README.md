# Barthelemy

Stub del tema Barthelemy per il monorepo `base_techplanner_fila5`.

Stato attuale: la cartella contiene solo documentazione (`docs/`). Non esistono ancora codice (`app/`) ne' risorse (`resources/`); i file di configurazione presenti (`composer.json`, `package.json`, `vite.config.js`, `tailwind.config.js`) sono segnaposto.

## Requisiti

- PHP ^8.3
- Laravel (monorepo `laravel/`)

## Installazione

Il tema vive in `laravel/Themes/Barthelemy` e non ha un repository proprio: segue il monorepo. Nessun passo di installazione specifico finche' il tema non avra' codice.
