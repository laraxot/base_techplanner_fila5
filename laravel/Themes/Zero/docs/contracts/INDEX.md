# Theme Zero behavioral contract index

Inventario machine-readable dei contratti di comportamento del tema **Zero**.
Il tema non ha Action (`app/` contiene solo `.gitkeep`) e le sue superfici sono viste
Blade anonime senza classe PHP: non ci sono file `type: contract`. La tabella di
lavoro e' in [index.md](index.md).

## Contratti

Nessuno (il tema non ha Action ne' classi PHP).

## Autore

Usa il template [_template.md](_template.md) e il formato descritto in [README.md](README.md).
Se una vista del tema diventasse un componente con classe (`View\Components\...`),
scrivere allora un `presentation-contract` con `contract: <FQCN>`.
