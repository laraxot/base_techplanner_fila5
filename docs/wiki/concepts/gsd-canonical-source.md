# GSD Canonical Source

## Regola

Nel progetto, `GSD` significa sempre **Get Shit Done**:

- repository canonico: https://github.com/gsd-build/get-shit-done
- documentazione canonica: https://gsd-build-get-shit-done.mintlify.app/

Non interpretare `GSD` come abbreviazione generica di "fare cose". Quando l'utente chiede `GSD`, usare il workflow spec-driven/context-engineered di `gsd-build/get-shit-done`.

## Uso operativo

- BMAD chiarisce requisiti, story e contesto.
- GSD organizza il lavoro in fasi, piani, wave execution e verifica.
- Ruflo puo' memorizzare checkpoint e stato operativo, ma non sostituisce GSD.
- Il repository locale contiene anche la skill `GSD (Get Shit Done)`: usarla quando l'utente nomina GSD.
