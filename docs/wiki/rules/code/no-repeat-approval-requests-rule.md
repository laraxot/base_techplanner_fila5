# No Repeat Approval Requests Rule

> Indice: [./00-INDEX.md](./00-INDEX.md)
> Canonico: [../docs/governance/command-approval-discipline.md](../docs/governance/command-approval-discipline.md)

## Regola

Non chiedere di nuovo approvazioni per discovery innocua gia approvata o chiaramente indesiderata dall'utente. Cambiare strumento o strategia prima di generare un nuovo prompt di allow.
