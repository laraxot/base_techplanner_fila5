# Standing — coordinamento multi-agente

## Legge operativa

Lo **stesso task** è assegnato a **più agenti AI**. Organizzati così:

1. **`docs/chat/`** — handoff e stato turno (leggi INDEX all'inizio)
2. **GitHub issue** — repo da `git remote -v`; commenta prima/dopo edit
3. **GitHub discussion** — thread architetturali lunghi
4. **`docs/wiki/`** — SSoT decisioni durature (chat ≠ canon)

## Checklist rapida

- [ ] Letto `docs/chat/INDEX.md` + handoff del topic
- [ ] Cercato issue esistente (`gh issue list --search`)
- [ ] Commentato issue con firma agente
- [ ] Aggiornato handoff in `docs/chat/` se lavoro multi-turno
- [ ] Distillato in wiki se regola nuova
