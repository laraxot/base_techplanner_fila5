## Dev Notes

### Error Category Strategies

**Cast Errors (cast.string, cast.int)**
- **Pattern:** `Cannot cast mixed to string/int`
- **Root Cause:** Method parameters or property values typed as `mixed` without narrowing
- **Fix:** Replace `mixed` with concrete type (check calling context, use `|` union if needed)
- **Example:** `public function foo(mixed $val): void` → `public function foo(string|int $val): void`
- **Verification:** Run PHPStan after each fix; no new errors allowed
- **Source:** [Source: bashscripts/ai/wiki/rules/phpstan-type-coverage-cleanup.md] [Source: laravel/phpstan.neon level: max]

**Generics Errors (generics.notGeneric)**
- **Pattern:** `PHPDoc tag @use contains generic type ... but trait ... is not generic`
- **Root Cause:** `HasXotFactory` trait used with generic `<Factory<static>>` but trait not declared generic
- **Fix Strategy (H1 - RECOMMENDED):** Make `HasXotFactory` trait generic:
  ```php
  /**
   * @template TFactory of \Illuminate\Database\Eloquent\Factories\Factory<static>
   */
  trait HasXotFactory { ... }
  ```
  Then keep `@use HasXotFactory<Factory<static>>` on model classes.
- **Fallback (H2):** Remove `@use` annotations and rely on trait methods directly (verify factory() calls still type-safe)
- **Source:** [Source: bmad-output/investigation-hasxotfactory-phpstan.md#H1] [Source: Modules/Xot/app/Models/Traits/HasXotFactory.php]

**Type Coverage Errors (typeCoverage.constantTypeCoverage)**
- **Pattern:** `Out of N possible constant types, only M actually have it`
- **Root Cause:** Class constants declared without explicit type (pre-PHP 8.3)
- **Fix:** Add explicit `: type` to constant declarations
- **Example:** `const FOO = ['a', 'b'];` → `const FOO: array = ['a', 'b'];`
- **Verification:** PHPStan output shows % increase in coverage
- **Source:** [Source: phpstan.neon paramTypeCoverage.constantTypeCoverage configured]

**Deprecated Method Errors (method.deprecated)**
- **Pattern:** `Call to deprecated method getTableColumns()` / `getTableFilters()`
- **Root Cause:** Filament v4→v5 API change (override `table()` method instead)
- **Fix:** Replace calls to `getTableColumns()` / `getTableFilters()` with resource `table()` method override
- **Example:** Old: `$resource->getTableColumns()` → New: `$resource->table(table: $table)` in Resource class
- **Source:** [Source: Filament v5 migration guide] [Source: Activity/tests/Feature/FilamentTest.php:181]
