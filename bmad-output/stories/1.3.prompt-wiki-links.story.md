# 1.3: Prompt Wiki Links

**Story ID:** 1.3
**Epic:** 1 — Prompt Directory Analysis & Cleanup
**Slug:** prompt-wiki-links
**Status:** ready-for-dev

> Owned by planning until `done`. Sized to one dev-day (~2-8h). No story points.

## Story

As a **documentation maintainer and AI agent**,
I want **prompt content that duplicates wiki knowledge to be replaced with links**,
so that **the wiki is the single source of truth and prompts stay lean and operational**.

## Acceptance Criteria

1. All prompt content sections that duplicate `docs/wiki/` material are replaced with `[[wiki-link]]` syntax.
2. No prompt contains >50 lines of inline content that has an equivalent wiki page.
3. All wiki links resolve (no broken `[[...]]` references) — verified by `wiki-lint` skill.
4. Each prompt's "See Also" section (in front matter or footer) lists its wiki dependencies.
5. Total `.md` line count in `bashscripts/docs/prompts/` reduced by at least 20% (DRY effect).

## Tasks / Subtasks

- [ ] Map prompt → wiki equivalents (AC: #1, #2)
  - [ ] For each prompt, find overlapping wiki pages
  - [ ] Mark sections to extract into wiki
  - [ ] Create new wiki pages for content that has no home
- [ ] Extract duplicated content to wiki (AC: #1)
  - [ ] Move blocks to `docs/wiki/concepts/` or `docs/wiki/rules/`
  - [ ] Replace inline content with `[[wiki-page-slug]]` link
- [ ] Validate wiki links (AC: #3)
  - [ ] Run `wiki-lint` skill
  - [ ] Zero broken links
- [ ] Add "See Also" footer to each prompt (AC: #4)
  - [ ] List wiki dependencies
  - [ ] Use wikilink syntax `[[slug|Display Name]]`
- [ ] Verify line count reduction (AC: #5)
  - [ ] `wc -l bashscripts/docs/prompts/*.md` before/after
  - [ ] Report delta

## Dev Notes

- Wiki link syntax: `[[page-slug]]` or `[[page-slug|Display]]` per Obsidian convention [Source: docs/wiki/concepts/obsidian-flavored-markdown.md#wikilinks]
- Wiki location convention:
  - `docs/wiki/concepts/<slug>.md` — conceptual knowledge
  - `docs/wiki/rules/NNN-<slug>.md` — operational rules
  - `docs/wiki/patterns/<slug>.md` — implementation patterns
- Use `wiki-lint` skill to validate [Source: skills/wiki-lint]
- For wiki pages that don't exist yet, create them with the same YAML front matter standard as prompts [Source: 1.2.prompt-frontmatter-standardization]
- [Inference] Likely 5-10 new wiki pages will be created from extracted content

## Testing

- **Approach:** static analysis + skill invocation
- **Key scenarios:** all wiki links resolve, content deduplicated
- **Per-AC verification:**
  - AC #1 → manual review of 5 random prompts confirms wikilink replacement
  - AC #2 → `awk` count of inline lines per file
  - AC #3 → `wiki-lint` returns 0 broken links
  - AC #4 → grep for `## See Also` section in all prompts
  - AC #5 → `wc -l` delta report
- **Edge cases:** wikilinks that span multiple paragraphs, inline code that looks like wikilinks, wikilinks in code blocks (should not be processed)

## Dependency Maps

- **Blocks:** none
