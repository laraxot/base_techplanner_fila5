## Dev Notes

**Source:** PHPStan error, `UserContract` defines `$current_team_id` as `string|null`.

**Fix:** Line 81 in `Modules/User/app/Console/Commands/SetCurrentTeamCommand.php`:
```php
// Before
$user->current_team_id = (int) $team_id;
// After
$user->current_team_id = (string) $team_id;
```

The `$opts` array keys are already `int|string` (from `pluck('id', 'name')`) and `$team_id` comes from `select()` which returns the key. Casting to `string` aligns with the contract.
