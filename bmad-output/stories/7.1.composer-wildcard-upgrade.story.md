# BMAD Story: Composer Wildcard Upgrade — Phase 2B

**Epic**: PHPStan L10 + Dependency Stability  
**Story #**: 7.1  
**Date**: 2026-09-06  
**Owner**: Infrastructure coordinator  

## Issue

Both projects have `"nwidart/laravel-modules": "*"` in composer.json.
- Wildcard = unpredictable breaking changes
- Violates "always latest version" policy
- Must pin to explicit version from GitHub Releases

## Solution

1. Check GitHub: https://github.com/nwidart/laravel-modules/releases
   - Find latest stable version (e.g., v11.0.0, v12.0.0)
   
2. Update both projects:
   ```bash
   # base_techplanner_fila5
   cd /var/www/_bases/base_techplanner_fila5/laravel
   sed -i 's/"nwidart\/laravel-modules": "\*"/"nwidart\/laravel-modules": "^11.0"/g' composer.json
   
   # base_workorder_fila5
   cd /var/www/_bases/base_workorder_fila5/laravel
   sed -i 's/"nwidart\/laravel-modules": "\*"/"nwidart\/laravel-modules": "^11.0"/g' composer.json
   ```

3. Verify + update:
   ```bash
   composer update nwidart/laravel-modules
   ```

4. Test: PHPStan analysis for each project
   - If new errors: investigate nwidart version compatibility
   - If no new errors: commit

5. Commit:
   ```bash
   git add composer.json composer.lock
   git commit -m "chore: upgrade nwidart/laravel-modules to ^X.Y (explicit version)"
   git push origin dev
   ```

## Acceptance Criteria
