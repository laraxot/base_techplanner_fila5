# 1.4: Prompt Naming Fix

**Story ID:** 1.4
**Epic:** 1 — Prompt Directory Analysis & Cleanup
**Slug:** prompt-naming-fix
**Status:** ready-for-dev

> Owned by planning until `done`. Sized to one dev-day (~2-8h). No story points.

## Story

As a **documentation maintainer and AI agent**,
I want **all prompt files to follow the `NN-title-kebab.md` naming convention**,
so that **the directory is alphabetically ordered, sortable, and stable across renames**.

## Acceptance Criteria

1. All `.md` files in `bashscripts/docs/prompts/` match regex `^\d{2}-[a-z0-9-]+\.md$`.
2. Date-based filenames (e.g. `2024-01-15-foo.md`) renamed to `NN-foo.md` (where `NN` is the next available sequence number).
3. Files without numeric prefix get one assigned based on alphabetical order of their slug.
4. `git mv` used for all renames (history preserved).
5. No collisions: all sequence numbers are unique.
6. Each file's front matter `slug` field matches its filename (without extension and numeric prefix).

## Tasks / Subtasks

- [ ] Audit current filenames (AC: #1)
  - [ ] `ls bashscripts/docs/prompts/` → list of filenames
  - [ ] `grep -E '^[0-9]+-' | sort` vs. `grep -vE '^[0-9]+-' | sort`
- [ ] Identify date-based files and conflicting numbers (AC: #2, #3, #5)
  - [ ] Match `^[0-9]{4}-[0-9]{2}-[0-9]{2}-` pattern
  - [ ] Build rename map: old name → new name
  - [ ] Resolve collisions by inserting gaps (use 05, 10, 15... or 01, 02, 03...)
- [ ] Execute renames via `git mv` (AC: #4)
  - [ ] `cd bashscripts/docs/prompts && git mv old-name new-name`
  - [ ] Verify with `git status`
- [ ] Sync front matter `slug` to match (AC: #6)
  - [ ] For each renamed file, update `slug:` field in front matter
  - [ ] Remove `NN-` prefix from slug (slug = title-kebab only)
- [ ] Verify zero collisions and pattern match (AC: #5, #1)
  - [ ] `ls | sort | uniq -d` returns empty
  - [ ] `ls | grep -cE '^[0-9]{2}-[a-z0-9-]+\.md$'` equals total count

## Dev Notes

- Naming convention: `NN-title-kebab.md` where `NN` is `00-99` zero-padded [Source: docs/wiki/concepts/agent-bootstrap-compact.md#naming]
- Sequence allocation strategy:
  - Reserve multiples of 5 (00, 05, 10, 15...) for primary prompts
  - Reserve multiples of 10 (10, 20, 30...) for major categories
  - Use `git mv` to preserve rename history [Source: docs/wiki/git/forward-only-strategy.md]
- Update wiki links that point to renamed files [Source: 1.3.prompt-wiki-links — wiki links may reference old paths]
- Some files may already be correct (e.g. `00-master-prompt.md`); only modify the offenders
- [Inference] ~10-15 files likely need renaming (date-based or missing prefix)

## Testing

- **Approach:** static analysis (filename pattern + git log)
- **Key scenarios:** all files match convention, history preserved
- **Per-AC verification:**
  - AC #1 → `ls *.md | grep -vE '^[0-9]{2}-[a-z0-9-]+\.md$'` returns empty
  - AC #2 → no filenames start with year
  - AC #3 → all files have numeric prefix
  - AC #4 → `git log --follow <new-name>` shows history
  - AC #5 → `ls | sort | uniq -d` returns empty
  - AC #6 → cross-check front matter `slug` = filename minus `NN-` and `.md`
- **Edge cases:** files that already match (no-op), files with special characters, files that would collide with existing names
