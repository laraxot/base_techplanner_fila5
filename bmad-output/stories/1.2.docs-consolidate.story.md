# 1.2: Consolidate module docs (max 6 .md per module root)

**Story ID:** 1.2
**Epic:** 1 — Rewrite 16 Module PHILOSOPHY.md
**Slug:** docs-consolidate
**Status:** backlog

## Story

As a **maintainer**,
I want every module `docs/` folder to contain at most 6 `.md` files,
so that documentation is structured, minimal, and convention-compliant.

## Acceptance Criteria

1. Each `laravel/Modules/{ModuleName}/docs/` has ≤ 6 `.md` files.
2. Files follow naming convention: `PHILOSOPHY.md`, `README.md`, `ARCHITECTURE.md`, `ACTIONS.md`, `CONTRIBUTING.md`, `CHANGELOG.md` (or similar 6 max).
3. Content from removed files is merged into remaining docs (no data loss).
4. YAML front matter present on all docs files (title, module, type, tags, updated).
5. No "FixCity" references (modules agnostic).

## Tasks / Subtasks

- [ ] Inventory current `.md` files per module (AC: #1, #2)
  - [ ] Identify files to keep (priority: PHILOSOPHY, README, ARCHITECTURE)
  - [ ] Identify files to merge/archive
- [ ] Merge content into ≤ 6 files (AC: #3)
  - [ ] Ensure front matter on all files (AC: #4)
  - [ ] Remove FixCity references (AC: #5)
- [ ] Verify with grep and file count (AC: #1)

## Dev Notes

- Source: `ls laravel/Modules/*/docs/` shows 50-300 files per module.
- [Inference] The 6-file convention likely comes from INDEX.md archetypes.
- Archive merged content under `docs/archived/` with index.

## Testing

- **Approach:** bash count + grep
- **Key scenarios:** `find laravel/Modules/*/docs -name "*.md" | wc -l` ≤ 6 per module
- **Edge cases:** preserve subdirectories for assets (not .md)
