# 5.1: Multi-Agent Coordination Workflow

**Story ID:** 5.1
**Epic:** 5 — Coordination & Validation
**Slug:** workflow-coordination
**Status:** backlog

## Story
As a **multi-agent team**, I want a clear workflow for creating stories, getting validation, and coordinating with other agents before any development.

## Acceptance Criteria
1. BMAD story created for ANY work
2. Story must be validated by other agents BEFORE development
3. Coordination with agents who will do the dev work
4. Git workflow per Rule 019: fetch → merge → add -A → commit → push -u (no --force)
5. Constraints: no phpstan.neon mods, no @phpstan-ignore, replace mixed where possible
6. Quality gates after each change: phpstan + phpmd + phpinsights + pest

## Workflow
```
1. CREATE STORY (bmad create story)
2. SHARE with other agents (validation)
3. COORDINATE with assigned dev agent
4. WAIT for dev to complete
5. VALIDATE quality gates
6. GIT SYNC per module
7. UPDATE second brain
```

## Dev Notes
- Never develop directly without story validation
- Each agent owns specific modules
- Use shared second brain for context
