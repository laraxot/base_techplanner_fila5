## Dev Notes

**Error detail:**
- Lines 130, 142, 161: `Cannot cast mixed to string.` (cast.string)
- Lines 131, 143, 162: `Call to function is_string() with string will always evaluate to true.` (function.alreadyNarrowedType)

**Root cause:** The value is inferred as `mixed`, then cast to string with `(string)$value`. PHPStan rejects the cast and complains. The redundant `is_string()` checks that follow suggest the narrowing happened elsewhere but wasn't visible to PHPStan.

**Fix strategy:**
1. Find what produces the `mixed` value (likely `pluck('column')` or array access)
2. **Never use type cast** `(string)` — it doesn't narrow, it hides the problem
3. Instead: use `is_string()` guard or type hint on source
4. If guard exists and PHPStan still doesn't see it, restructure to make guard immediately before use
5. Remove redundant `is_string()` calls after narrowing is established

**Example:**
```php
// WRONG (triggers cast.string + function.alreadyNarrowedType)
$mixed = $item->getAttribute(); 
$str = (string)$mixed;  // ❌ cast
if (is_string($str)) { } // ❌ redundant

// CORRECT
$mixed = $item->getAttribute();
if (!is_string($mixed)) return;
$str = $mixed;  // ✅ narrowed, no cast needed
```

**Source:** [PHPStan docs — cast.string](https://phpstan.org/error-identifiers/cast.string), [function.alreadyNarrowedType](https://phpstan.org/error-identifiers/function.alreadyNarrowedType)
