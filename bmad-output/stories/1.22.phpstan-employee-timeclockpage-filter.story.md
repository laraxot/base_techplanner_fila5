## Dev Notes

**Source:** PHPStan errors - `variable.undefined $data`, `offsetAccess.nonOffsetAccessible`.

**File:** `Modules/Employee/app/Filament/Resources/WorkHourResource/Pages/TimeClockPage.php`

**Fix pattern:**
```php
->query(function (Builder $query, array $filterData): Builder {
    /** @var string|null $dateFrom */
    $dateFrom = $filterData['date_from'] ?? null;
    /** @var string|null $dateTo */
    $dateTo = $filterData['date_to'] ?? null;

    return $query
        ->when(is_string($dateFrom) && $dateFrom !== '', 
            fn (Builder $q): Builder => $q->whereDate('timestamp', '>=', $dateFrom))
        ->when(is_string($dateTo) && $dateTo !== '', 
            fn (Builder $q): Builder => $q->whereDate('timestamp', '<=', $dateTo));
})
```

Also change `->form([])` to `->schema([])` for Filter.
