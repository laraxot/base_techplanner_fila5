# Story 3.4: Fix PHPStan HasXotFactory Generic Type Errors

**Story ID:** 3.4
**Epic:** 3 — PHPStan Quality Gate
**Slug:** phpstan-hasxotfactory-generic-fix
**Status:** ready-for-dev

## Story

As a **maintainer**,
I want the `HasXotFactory` trait to be properly typed for PHPStan Level 10,
so that PHPStan `analyse Modules` returns zero errors.

## Source: Investigation

Case file: `bmad-output/investigation-hasxotfactory-phpstan.md`

## Current State

- Trait `HasXotFactory` is NOT generic (`@template TFactory`)
- When models use `@use HasXotFactory<SomeFactory>`, PHPStan reports `generics.notGeneric`
- When `@use` is removed, models report `missingType.generics` on `factory()` method

## Solution: Make Trait Generic

1. Add `@template TFactory of Factory<*>` to trait docblock
2. Add `@use HasXotFactory<ConcreteFactory>` to each model using the trait
3. Verify PHPStan returns 0 errors

## Acceptance Criteria

1. `cd laravel && ./vendor/bin/phpstan analyse Modules --memory-level=-1` returns **0 errors**
2. No `@phpstan-ignore` added for new errors
3. No edits to `phpstan.neon` (user-only per second-brain rule)
4. PHPMD passes on modified modules
5. Pest tests pass on modified modules
