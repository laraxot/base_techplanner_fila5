# CMS duplicate page slug diagnostics

## User story

As a developer maintaining tenant CMS content, I want duplicate page slugs to
identify the exact conflicting records, so that I can repair the JSON source
without guessing which query failed.

## Acceptance criteria

- [x] Duplicate page slugs identify model, count, slug, side, and record IDs.
- [x] The CMS does not silently select an arbitrary duplicate with first().
- [x] Missing slugs still return an empty block list.
- [x] PHPStan passes for the changed trait.
- [x] Formatting validation passes.
- [ ] CMS Pest suite passes once techplanner_data_test is available.
