## Dev Notes

**Error detail:** `Parameter #1 $value of function strval expects bool|float|GMP|int|resource|string|null, mixed given.`

**Root cause:** `strval()` receives a value inferred as `mixed` type. Common in: `pluck()`, array access without type hint, dynamic property access.

**Fix strategy:** 
- If `$value` comes from `pluck('id')` → narrow with `is_int()` / `is_string()` before passing to `strval()`
- If from array access → add type hint to source array or narrow at call site
- Never use type cast `(string)` — that hides the problem. Use `is_string()` check instead.

**Source:** [PHPStan docs — argument.type](https://phpstan.org/error-identifiers/argument.type)
