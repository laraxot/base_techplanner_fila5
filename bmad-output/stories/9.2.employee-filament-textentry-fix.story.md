## Dev Notes

### Current Error Pattern (from PHPStan scan 2026-09-07)

**Primary Error:**
```
class.notFound: Filament\Forms\Components\TextEntry
Location: Multiple widget files (Lines 63, 73, 55, 56, 52, 60, 74, 75)
```

**Cascading Errors:**
```
method.nonObject: Cannot call method content() on mixed
argument.type: array{mixed} given, expected array<Htmlable|string>
```

Root cause: In Filament v5, the `TextEntry` class was moved or API changed. Previously in `Filament\Forms\Components`, now likely in `Filament\Infolist\Components` or restructured.

[Source: PHPStan scan Employee module 2026-09-07] [Source: bmad-output/stories/9.1.phpstan-l10-phase2-fixes.story.md#Owned-File-Scope]

### Filament v4 → v5 Breaking Changes (Likely)

1. **TextEntry moved**: From `Forms\Components` to `Infolist\Components` (v5 uses Info Lists for display, Forms for input)
2. **Method signature**: v4 `schema()` may require different typing in v5
3. **Widget compatibility**: Widgets may inherit from different base in v5

### Investigation Strategy

1. Check Filament v5 docs: search for "TextEntry" in official docs
2. Look for "migration guide" or "breaking changes" in Filament repo
3. If TextEntry moved to Infolist, import pattern:
   ```php
   use Filament\Infolist\Components\TextEntry;
   ```
4. Adapt method calls to v5 API (likely same ::make()->content() pattern, different parent)
