**Fix patterns:**

For redundant casts after `is_string()`:
```php
// Before (wrong - cast already string)
if (is_string($userId)) {
    $url = '/profile/' . (string) $userId;  // redundant cast
}

// After (correct)
if (is_string($userId)) {
    $url = '/profile/' . $userId;
}
```

For mixed array access:
```php
// Before (wrong)
$primaryNav = $data['primary_nav'];

// After (correct)
if (! is_array($data) || ! is_string($data['primary_nav'] ?? null)) {
    $this->fail('Invalid nav data');
}
$primaryNav = $data['primary_nav'];
```
