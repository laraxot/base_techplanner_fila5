# 2.2: Fix Employee Type Mismatches

**Story ID:** 2.2
**Epic:** 2 — Employee Module Fixes
**Slug:** employee-type-mismatches
**Status:** ready-for-dev

## Story
As a developer,
I want to fix `strval()`/`intval()` parameter type issues in Employee module,
so that PHPStan type errors are resolved without breaking runtime behavior.

## Acceptance Criteria
1. All `strval()` calls receive properly typed parameters
2. All `intval()`/`(int)` casts have type guards
3. PHPStan type errors resolved

## Tasks / Subtasks
- [ ] Add `is_string()` guards before `strval()` (AC: 1)
- [ ] Add `is_numeric()` guards before `(int)` casts (AC: 2)
- [ ] Run `phpstan analyse Modules/Employee/` (AC: 3)

## Dev Notes
- Pattern: `is_string($val) ? strval($val) : ''` instead of bare `strval($val)` [Source: tech-spec.md#FR-003]
- Pattern: `is_numeric($val) ? (int) $val : 0` instead of bare `(int) $val` [Inference from previous fixes]
