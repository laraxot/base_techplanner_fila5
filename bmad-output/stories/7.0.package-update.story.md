# Package Update Rules
- Always use latest version (check GitHub releases / Packagist)
- No downgrade allowed
- Update composer.json in each module (Activity, Geo, Lang, Media, Notify, Seo, UI, User, Xot)
- After update: composer update, PHPStan check, quality gates, git sync
- Larastan (Seo): check https://github.com/larastan/larastan
